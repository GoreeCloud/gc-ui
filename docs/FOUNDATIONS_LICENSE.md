# GoreeCloud UI license decision

Owner decision (2026-10-17): Apache-2.0 for GoreeCloud-owned UI source and Foundations v1.0.0. This library-specific choice supersedes the default AGPL fallback under GoreeCloud Software Licensing policy. It favors broad embedding and an express patent grant.

The Foundations package contains no third-party icon packs. Assets under assets/third-party retain their upstream licenses and notices. This license decision does not establish a passed release, npm registry authority, or completed migration.
