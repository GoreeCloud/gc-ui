# GC UI premium visual direction — experimental review

**Status:** Candidate, not a founder-approved official identity or release. No image-generation service was used. New original SVG source exists in the canonical GoreeCloud/brand-assets/products/gc-ui/candidates/ review branch and byte-identical preview copies under assets/candidates/. The manifest is SHA-256 pinned and the two repositories' candidate bytes must match exactly.

## Intent

Respond to the founder's November 6 request for a distinctive premium GC UI logo, icon, artwork and more polished interfaces. Aperture Weave uses three independently folded planes to signify existing Canvas, Surface and Lens responsibilities. Experimental Components Lab and Experience Studio reference views introduce a richer editorial hero, original interface artwork, coherent type scale, controlled depth, solid Surface cards, responsive spacing and subtle focus/hover cues. A light/dark identity board explicitly labels proposed lockups UNAPPROVED.

**Scope:** Existing canonical navigation icons and favicons remain in place; official vector identities, source hash assertions, semantic tokens, Stable Foundations exports, consumer apps, builds and production remain unchanged. The preview does not promote the candidate to official brand status.

## Verification contract

- Source and manifest checks: SHA-256 and byte equality across canonical brand candidate and consumer preview, valid self-contained SVG, no scripts, foreign objects or external images.
- Browser checks: actual artwork/logo assets load; light/dark layout at phone, tablet and desktop widths; no page horizontal overflow, clipped headings or overlays; candidate warning is visible; official headers and favicons remain; keyboard focus, reduced motion and high/forced color controls keep working.
- Accessibility: descriptive alt for meaningful showcase logos and artwork, decorative header marks have empty alt text, high/forced-color solid fallbacks, no nonessential interactive art or external tracking.
- Visual quality: real browser captures at multiple widths and themes for founder-led premium acceptance; automated geometry is not full visual acceptance.

## Approval gate

Before adopting a new official app icon, symbol, wordmark, raster distribution, launcher/favicon or migrating other products, explicitly review and approve the candidate. Central brand-assets is the source master; consumer copies must be revision-pinned and identical. Verify platform rendering and generate supported derivatives after acceptance. Do not silently rewrite the existing approved identity or call an alpha preview Stable.
