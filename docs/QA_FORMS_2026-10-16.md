## Implementation and maturity

Four formerly specification-only patterns now have native-first **experimental** references:

| ID | Pattern | Specimen |
|---|---|---|
| F10 | Text area | Resizable labeled editor with character count and minimum-length feedback |
| F11 | Search field | Keyboard-driven combobox suggestions, explicit clear control and announced results |
| F22 | Form validation summary | Focusable error summary linked to invalid native inputs, preserving entered values |
| O53 | Empty state | Explanation and single accessible reset action for zero matching projects |

The canonical catalog remains **63 patterns total: 28 experimental, 35 specified, 0 stable**. The reference is accessible at `lab/forms.html`; shared styles are in `styles/gc.v1.components.css`. Sample controller logic in `lab/forms.mjs` is not represented as a stable package export. See `docs/FORMS_CONTRACT.md`.

## Lifecycle defects corrected

- Replaced toast event handlers cannot re-arm a timeout and dismiss a newer toast.
- A tab initially marked selected but `aria-disabled="true"` now falls back to an enabled tab.
- Forms Lab's skip link is offscreen at rest and visible on keyboard focus. The utility lives in the shared component CSS.
- Chromium's built-in search cancel glyph is hidden when the GC UI demo provides its own explicit, named Clear search button.

## Visual review

During direct inspection of the Forms Lab's 1440px light and 375px dark renderings, two issues were detected: the skip link appeared when unfocused and Chromium showed two adjacent clear icons. Both were corrected and protected with browser/source regressions. The subsequent captured fixtures and interaction tests passed. **The full screenshot collection has not received formal visual approval.**

The forms examples are entirely local browser simulations. No real account data, network requests, or form submissions are implemented.
