# GC UI premium visual direction — experimental review

**Status:** Founder-approved Aperture Weave identity direction (November 6, 2026); consumer/source adoption in review, NOT a deployed application or stable release. No image-generation service was used. New original SVG source exists in the canonical GoreeCloud/brand-assets/products/gc-ui/candidates/ directory and byte-identical preview copies under assets/candidates/. The manifest is SHA-256 pinned and the two repositories' candidate bytes must match exactly.

## Intent

Respond to the founder's November 6 request for a distinctive premium GC UI logo, icon, artwork and more polished interfaces. Aperture Weave uses three independently folded planes to signify existing Canvas, Surface and Lens responsibilities. Experimental Components Lab and Experience Studio reference views introduce a richer editorial hero, original interface artwork, coherent type scale, controlled depth, solid Surface cards, responsive spacing and subtle focus/hover cues. A light/dark identity board identifies the founder-approved mark and separates source adoption from unverified native app deployment.

**Scope:** The local GC UI header/favicon source files are replaced by exact-byte founder-approved masters and source-hash pins on a dedicated review branch. Canonical masters are updated in brand-assets first; semantic tokens, Stable Foundations exports, other ecosystem product identities and production deployments remain unchanged.

## Verification contract

- Source and manifest checks: SHA-256 and byte equality across canonical brand candidate and consumer preview, valid self-contained SVG, no scripts, foreign objects or external images.
- Browser checks: actual artwork/logo assets load; light/dark layout at phone, tablet and desktop widths; no page horizontal overflow, clipped headings or overlays; founder approval and staged rollout note is visible; header and favicon references still resolve to the canonical source path; keyboard focus, reduced motion and high/forced color controls keep working.
- Accessibility: descriptive alt for meaningful showcase logos and artwork, decorative header marks have empty alt text, high/forced-color solid fallbacks, no nonessential interactive art or external tracking.
- Visual quality: real browser captures at multiple widths and themes for founder-led premium acceptance; automated geometry is not full visual acceptance.

## Approval gate

The founder approved the exact Aperture Weave identity in chat after viewing the actual rendered assets on November 6, 2026. Before shipping any native app bundle, platform launcher, public profile, or migrating other ecosystem products, verify each consumer separately. Central brand-assets is the source master; consumer copies must be revision-pinned and identical. Verify platform rendering and generate supported derivatives after acceptance. The approved identity intentionally supersedes the prior GC-letterform logo. Do not call the alpha workspace Stable, or claim deployed native and consumer migrations without evidence.
