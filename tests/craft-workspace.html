01 / Request to advisory

One deliberate path from hold to review

A clear sequence should replace decorative statistics. The information below describes the intended policy, not an operating queue.

  1. Verify the owner

    Check the caller and confirm the original application still holds the exact requested object.

    Identity and owner attestation
  2. Reserve a private scan

    Reject a reused lease or exhausted capacity before passing any held bytes to the engine.

    Replay guard and bounded admission
  3. Record an advisory result

    Check what was scanned, preserve the hold on uncertainty, and leave final release authority with the owner.

    Advisory only · never auto-release

What happens after detection?

Review a result without releasing the file

An advisory result must be bound to the exact request and held file. A clean result may qualify for owner review; it cannot publish or release content. Unknown or failed scans retain the pending hold.
